# Marks Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Marks" section (desktop and Android) that lists every graded item of the tracked courses, grouped by university and then by subject, showing the grade as the platform displays it.

**Architecture:** Frontend only. A pure grouping module turns `TrackerDto` into university → course → item groups. A `MarksPage` reads the existing `get_tracker` query and reuses the tracker's details panel. A route and a navigation item expose it, so the sidebar and the Android bottom tab bar both get it from the shared nav list.

**Tech Stack:** React 19, TypeScript (strict), React Query 5, react-router 7, Tailwind v4, Vitest with Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-15-marks-design.md`

**Interfaces:**
- Consumes:
  - `TrackerDto`, `LmsItemDto`, `LmsUniversityDto` (`src/lib/api/types.ts`)
  - `api.getTracker` and `queryKeys.tracker`
  - `platformEntry`, `compareEntries` (`src/features/tracker/entries.ts`)
  - `ItemDetailsModal` or `EntryDetailsModal` with `useOpenEntry` (`src/features/tracker/`)
  - `KIND_LABELS`, `courseLabel` (`src/features/tracker/labels.ts`)
  - `formatDate` (`format.ts`)
- Produces:

```ts
// src/features/marks/groupMarks.ts
export interface CourseMarks { courseId: number; courseName: string; courseShortName: string | null; items: LmsItemDto[] }
export interface UniversityMarks { universityId: number; universityName: string; courses: CourseMarks[] }
export function groupMarks(data: Pick<TrackerDto, 'items' | 'universities'>): UniversityMarks[];
```

Rules:
- **What goes in:**
  - Keep items with `grade !== null`.
  - Universities follow `data.universities` order.
  - Universities and courses with no marks are omitted.
- **Sorting:**
  - Courses sort by `courseName` with `new Intl.Collator(undefined, { sensitivity: 'base', numeric: true })`, ties by `courseId`.
  - Items sort with `compareEntries(platformEntry(a), platformEntry(b))`, which puts the earliest due date first, undated last, then title.
- **Page:**
  - `h1` "Marks" uses `PAGE_TITLE`.
  - Each university is a `section` with an `h2` of its name.
  - Each course is `<details open>`, whose summary shows the course name, the short name in muted text when present and different, and the mark count. Reuse the dashboard's collapsible summary look; extract a small shared `CollapsibleSummary` from `src/features/tracker/ItemGroups.tsx` only if it isn't already exported.
- **Rows** (`li`, using the existing row classes from `src/features/tracker/rowStyles.ts`):
  - The title is a button (with a `title` attribute) that opens the details panel.
  - Muted `KIND_LABELS[kind]` and the due date via `formatDate(dueAt)`, or "No date".
  - The grade's `display` text, emphasised (e.g. `font-semibold`).
- **Empty states:**
  - No universities: "No marks yet." and a button "Add a university" that navigates to `/universities`.
  - Universities but no marks: "No marks yet. Graded work appears here after a sync."
- **Loading and errors:** "Loading…" while loading; on error, `ErrorMessage` with `toCommandError`.
